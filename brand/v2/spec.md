# Intune 标识使用规范 · 同心 Concentric

## 1. 标识是什么

上下各有一个 40° 缺口的圆环，正中是精确同心的实心圆点。

| 形态 | 含义 |
| --- | --- |
| 左右两条弧 | 两个声部：你的音 与 标准音 |
| 12 点 / 6 点的缺口 | 垂直方向是音高轴，缺口是轴的出口 |
| 正中的实心点 | 你唱出的那个音 |
| 同心 | 两点精确重合，偏差为零 —— 这就是 in tune 的字面意思 |
| 弧与点之间的留白 | 容错空间 |

## 2. 几何与比例系统

画布 1024 × 1024，基准单位 8px（1024 = 128u）。

| 项 | 值 | 落在哪个系统上 |
| --- | --- | --- |
| 点半径 | 120（15u） | 8u 网格 |
| 环内半径 | 360（45u） | **3:1**（= 3 × 点半径） |
| 留白环宽 | 240（30u） | **2:1**（= 2 × 点半径） |
| 环笔宽 | 72（9u） | 8u 网格 |
| 缺口 | 40° @ 12 点 / 6 点 | — |
| 外直径 | 864（108u） | 8u 网格 |

尺寸全部由 `brand/v2/build.py` 计算，改一个参数即可重算全部产物。

## 3. 色彩

| 格式 | 值 |
| --- | --- |
| HEX | #1B4A63 |
| RGB | (27, 74, 99) |
| CMYK | (73, 25, 0, 61) |
| Pantone | 7690 C（近似） |
| 白底对比度 | **9.52:1**（AAA） |

单色使用，不使用渐变、不使用第二种色相。

## 4. 净空区与最小尺寸

- **净空区**：外框外扩 48 单位（≈ 外直径的 5.5%），任何元素不得进入。
- **最小尺寸**：数字场景 **24px**；印刷 **8mm**。
- **32px 及以下**：切换到 `mark-compact.svg`（环加粗到 120、点放大到 r=172、缺口收窄到 30°），保证小尺寸不断裂。

## 5. 变体清单

| 文件 | 用途 |
| --- | --- |
| `mark.svg` | 主标（1024 画布，含构建注释） |
| `mark-tight.svg` | 主标裁剪版（含净空区，网页/App 用这个） |
| `mark-compact.svg` | ≤32px 降级版 |
| `mark-mono.svg` | 单色（单色印刷、雕刻） |
| `mark-reverse.svg` | 反白（深色底） |
| `favicon.svg` | 方形底板图标 |

## 6. 禁用

- 不得改变缺口角度或位置
- 不得给圆点做偏移（偏心 = 跑调，与品牌语义相反）
- 不得加渐变、投影、外发光
- 不得拉伸变形（只能等比缩放）
- 不得旋转
- 不得在净空区内放置文字或其他元素

## 7. 七项检查

| 检查 | 结果 |
| --- | --- |
| 剪影（单色填充可辨） | 通过 — 环 + 心，缺口保留 |
| 16px | 通过（用 compact 版：环 1.88px、点 5.4px） |
| 单色 | 通过 — 本身就是单色 |
| 模糊（低视力模拟） | 通过 — 仅两级层次，模糊后仍为"环 + 心" |
| 反白 | 通过（`mark-reverse.svg`） |
| 撞脸 | 通过（见报告：与 Target / Mastercard / Spotify 差异已列） |
| 语义安全 | 通过（180° 旋转、镜像、负空间、文化符号均已查，见报告） |
