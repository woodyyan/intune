2. 决策链

  • v1 阻尼波形（单线 + 基准横线 + 端点） → 淘汰：读成心电图／监护仪，语义被医疗抢走。
  • v2 调细笔画 + 加起音点 → 淘汰：结构没变，「横线 + 单波」的心电完形仍在。
  • v3 双线缠绕（两条声线收敛合一） → 淘汰：内部柳叶负空间太细密，40px 以下糊掉；整体像装饰曲线。
  • v4 完整环 + 同心点 → 淘汰：与 Target 靶心同构，且无任何构造决定。
  • v5 定稿：保留同心语义，加入构造决定——环在 12 点 / 6 点各开 40° 缺口， 把「垂直 = 音高轴、左右 = 两个声部」写进形状；再补一套 ≤32px 加粗降级版。

8. 决策记录

决策理由
为什么不做波形三轮实测都被读成心电图／监护仪；波形是「图表」不是「标志」
为什么不做双线缠绕内部负空间在 40px 以下糊掉，且形态偏装饰
为什么缺口开在 12/6 点而不是 3/9 点3/9 点开口时上下两条弧读作两个独立括号，中心松散；改到 12/6 点后左右弧环抱中心点，凝聚感成立
为什么缺口 40° 而不是更小小缺口在小尺寸会消失，等于把唯一的记忆点做成最脆弱的部分；40° 在任意尺寸都读得出
为什么主色是墨青 #1B4A63避开行业俗套的科技蓝与音乐常用的绿/紫；低饱和深色 + 大留白更接近「高级感」，且白底对比度 9.52:1 优于原品牌蓝
中央实心圆的国旗风险已规避：圆点在环内（有框架）+ 非红白配色，完形是准心不是旗面
