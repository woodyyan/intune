# Intune · 音准练习

一个帮唱歌跑调的人把音准练回来的小工具。每天 5 分钟、3 关，用即时音高反馈做闭环训练。

纯前端应用，无需后端，所有数据留在本地浏览器。

## 品牌标识

标识叫「同心 / Concentric」：**上下各开一个 40° 缺口的圆环，正中是精确同心的实心圆点。**

| 形态 | 含义 |
| --- | --- |
| 左右两条弧 | 两个声部：你的音 与 标准音 |
| 12 点 / 6 点的缺口 | 垂直方向是音高轴，缺口是轴的出口 |
| 正中的实心点 | 你唱出的那个音 |
| 同心 | 两点精确重合，偏差为零 —— 这就是 in tune 的字面意思 |
| 弧与点之间的留白 | 容错空间 |

**为什么不是波形**：前几轮做过阻尼波形和双线缠绕，实测都被读成心电图／监护仪，且内部负空间在 40px 以下会糊掉。同心结构只有两级层次，16px 依然成立。

**比例系统**（整数比 + 8px 网格，画布 1024 = 128u）：

| 项 | 值 |
| --- | --- |
| 点半径 | 120（15u） |
| 环内半径 | 360（45u）= **3 ×** 点半径 |
| 留白环宽 | 240（30u）= **2 ×** 点半径 |
| 环笔宽 | 72（9u） |
| 外直径 | 864（108u） |
| 缺口 | 40° @ 12 点 / 6 点 |

**主色**：共振紫 `#4F46E5`（RGB 79,70,229 / CMYK 65,69,0,10 / 白底对比度 6.3:1，AA）。标识单色使用；产品界面允许 `var(--brand-2)` 同色系渐变，第二色相仅用于数据可视化（`--accent` 薄荷青）。

| 文件 | 用途 |
| --- | --- |
| `src/components/Logo.tsx` | 页眉内联 SVG 组件（由脚本生成，勿手改） |
| `public/favicon.svg` | 浏览器图标：方形底板 + 反白降级图形 |
| `brand/v2/build.py` | 参数化几何生成器（改参数 → 全部产物重算） |
| `brand/v2/mark*.svg` | 主标 / 裁剪 / 降级 / 单色 / 反白 |
| `brand/v2/spec.md` | 使用规范（净空区、最小尺寸、禁用） |
| `brand/v2/preview.html` | 交互预览页（组合矩阵、缩放墙、场景、撞脸、语义安全） |
| `brand/v2/report.html` | 全量技术报告（决策链、几何、色彩、变体、决策记录） |

复现：`python3 brand/v2/build.py && python3 brand/v2/make_docs.py`。站内主色只改 `src/index.css` 的 `--brand` 一处。

## 核心设计

**1. 单关流程：听 → 静默 → 独立唱 → 回放对比**

跟着原唱一起唱时，你耳朵里同时有自己的声音和原唱的声音，大脑会把两者混在一起，反而听不出自己跑调。所以每一关都是：

1. 播放标准音（钢琴），可以看着节奏时间轴
2. **静默 2 秒**，心里先把这个音想一遍
3. 你独立演唱，全程无参考音，实时显示音分偏差
4. 回放对比：先放标准音，再放你的录音

中间那 2 秒静默是关键——跟着唱只能"抄"，独立唱才能暴露你脑子里真实的音高记忆。

**2. 三层练习载体**

| 层 | 载体 | 占比 | 说明 |
|---|---|---|---|
| 1 | 合成钢琴音 | 70% | 基频干净，检测最准，用于打地基 |
| 2 | 熟悉旋律的钢琴版 | 25% | 只存歌的音符骨架，用钢琴音色弹出来，熟悉感在但没有原唱干扰 |
| 3 | 真歌挑战 | 5% | 先听原唱再静音独立唱，作为通关实战 |

**3. 六阶渐进路径**

音域校准 → 听辨训练 → 长音模唱 → 音程跳进 → 旋律短句 → 完整乐句

解锁条件：**上一阶完成 4 次 + 最近 3 次平均分 ≥ 72 分**。首页每未解锁卡片都会实时显示进度。

**4. 自适应难度**

音分容差随难度从 62¢ 收紧到 25¢。连续 2 次 ≥ 85 分升级，连续 2 次 < 70 分降级，让难度始终卡在能力边缘。

**5. 音分而不是"对/错"**

跑调的人需要知道偏了多少、往哪偏：±20¢ 内几乎听不出，±50¢ 能听出"有点飘"，超过 50¢ 是明显跑调。100¢ = 1 个半音 = 钢琴上相邻两个键。

## 技术栈

| 层 | 选型 |
|---|---|
| 框架 | Vite + React 19 + TypeScript + Tailwind CSS v4 |
| 音源 | Tone.js 15（钢琴音色合成与节拍调度） |
| 音高检测 | 自研 YIN 算法（`src/lib/yin.ts`），麦克风经 AnalyserNode 采集、2 倍降采样、每 60ms 检测一次 |
| 数据 | localStorage（无后端） |

## 快速开始

```bash
npm install
npm run dev        # 开发服务器 http://127.0.0.1:5173
npm run build      # 类型检查 + 生产构建
npm run verify     # 核心算法回归测试（YIN 精度、评分、关卡生成）
```

使用提示：

- 用 **Chrome 或 Edge**，戴耳机清唱效果最好
- 麦克风需要 HTTPS 或 localhost，本地开发满足
- 首次练习建议先做 20 秒**音域校准**，后续所有练习都会落在你的舒适音域内

## 评分规则

单音得分 = 命中率 × 60 + 稳定性 × 20 + 起音准确度 × 20

判定做了三处人性化处理，避免机制问题误伤真实水平：

- **起音对齐**：自动把你实际开口的时刻对齐到时间轴，补偿 0.05–0.8 秒的反应延迟
- **起音宽限 0.1 秒**：跳过声带启动瞬间的不稳定段（这是生理现象，不是唱错）
- **离群剔除**：偏离中位数 250¢ 以上的帧视为误检（杂音、八度跳变）直接丢弃

## 数据说明

所有练习数据只存在这台设备的浏览器 localStorage 里，不上传任何服务器。成长面板提供「导出练习数据（JSON）」，可自行复盘。

## 项目结构

```
src/
  lib/        音高检测（yin/detector）、音源（audio）、评分（scoring）、课程（curriculum）、存储（storage）
  hooks/      麦克风引擎封装
  components/ 练习页、六阶首页、成长面板、校准、听辨、音分标尺、节奏时间轴
  data/       曲库（9 条公有领域旋律的音符骨架）
scripts/      算法回归测试
```
